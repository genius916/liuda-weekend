# 溜达 · 周末城市探索指南

> 周末不宅，去溜达。

一款面向大学生的周末城市探索工具，解决「周末去哪儿」的选择困难。

## 功能

- **智能推荐**：根据兴趣偏好 + 当日天气 + 预算范围，生成个性化活动推荐，附推荐理由与筛选条件
- **组队出发**：发布活动计划、报名加入，展示出发时间、集合地点、组队人数
- **打卡记录**：打卡 + 上传照片 + 简短评价，形成个人城市探索足迹
- **攻略分享**：发布、浏览、收藏、搜索图文攻略，按标签分类

## 技术栈

纯静态前端，无构建依赖：
- HTML5 + CSS3（设计令牌 + 移动优先）
- 原生 JavaScript（`localStorage` 本地持久化 + 演示数据）
- 内联 SVG 图标，零外部资源

## 目录结构

```
liuda/
├── index.html          # 单页应用入口
├── css/style.css       # 设计令牌 + 全部样式
├── js/
│   ├── icons.js        # 内联 SVG 图标库
│   ├── data.js         # 演示数据 + 存储层 + 推荐算法
│   └── app.js          # 页面渲染 + 交互逻辑
└── .github/workflows/  # GitHub Pages 自动部署
```

## 本地预览

直接用任意静态服务器打开，或双击 `index.html`。

## 部署

推送到 `main` 分支，GitHub Actions 自动部署到 GitHub Pages。
